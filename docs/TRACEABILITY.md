## How to read this matrix

- **Normative authority:** PRD-6.2 is authoritative for requirement wording and release criteria.
- **Ownership:** `BDFL (default)` is the documented role placeholder used because no delegated Accountable/Verification Owner is recorded; it is not a person identity.
- **Evidence boundary:** PRD text is not implementation evidence. Evidence in this matrix is limited to source inspection, schema/static validation, automated tests, manual acceptance, compatibility results, performance results, release verification, or approval records.
- **Manual/device evidence:** MA-01…MA-11 have not been executed on a real supported Android/Termux device in this environment; requirements depending on those checks remain `Partial` where applicable.
- **Release gate:** §47.3 remains blocked until required manual/device acceptance, compatibility, catalog-completeness, and traceability obligations are all evidenced.
